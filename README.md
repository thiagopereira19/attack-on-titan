# Attack on Titan | Por que você precisa assistir

> As muralhas estão de pé. Por enquanto.

Existem séries que você gostaria de assistir pela primeira vez de novo. _Attack on Titan_ é uma delas.

Este site existe por um motivo simples: convencer você a dar o play. Sem resumir a história, sem estragar nenhuma surpresa e sem exigir que você entenda de anime. Aqui você descobre o que esperar, quem vai acompanhar e por que tanta gente perdeu a noite de sono por causa dessa série.

Se você já assistiu, mande para aquele amigo que ainda não começou. Se não assistiu, só um aviso: depois do episódio 1, fica difícil parar.

**[Entrar no site](https://attack-on-titan26.netlify.app)**
